# tfidf-sum — Екстрактивна TF-IDF сумаризація (українська та англійська)

Інструмент командного рядка та Python-бібліотека для екстрактивної
сумаризації тексту: кожне речення оцінюється за TF-IDF вагами своїх термінів,
і речення з найвищою вагою повертаються **у початковому порядку** — це
зберігає зв'язність тексту.

Продакшн-переписування моєї курсової роботи з прикладної лінгвістики в
Київському національному університеті імені Тараса Шевченка.

## Можливості

- Працює для української та англійської одразу з коробки, з автовизначенням
  мови та стоп-словами під кожну мову окремо
- Без завантаження моделей: власний регулярковий спліттер речень із захистом
  від абревіатур (`тис.`, `напр.`, `Dr.`, `e.g.`) замінює punkt, тож
  інструмент однаково працює в будь-якому середовищі
- Розмір сумаризації за часткою (`--ratio 0.3`) або точною кількістю речень
  (`--sentences 5`)
- Опційна корекція перекосу на довгі речення (`--normalize`): оцінка за
  середньою вагою токена замість суми
- Показує коефіцієнт стиснення та терміни з найвищою вагою в документі
- Прозорий і детермінований — без навчання моделі, без звернень до API;
  повністю покрито тестами (pytest)

## Використання

```bash
tfidf-sum article.txt --sentences 3 --top-terms 5
```

```
Він фіксує реальну вживаність мовних одиниць у текстах певного стилю. На
основі частотних даних будуються статистичні моделі лексики. Лематизація
дозволяє звести словоформи до початкової форми і точніше рахувати частоти.

[3 sentences, compression: 32%]

top terms:
  мови        0.677
  частотний   0.663
  стилю       0.654
```

Речення не по темі в джерелі (у прикладеному прикладі — два речення про
Карпати в тексті про корпусну лінгвістику) коректно не потрапляють у
сумаризацію.

## Як бібліотека

```python
from tfidfsum import summarize

result = summarize(open("article.txt", encoding="utf-8").read(), ratio=0.3)
print(result.text)
print(result.compression, result.top_terms[:5])
```

## Обмеження та плани розвитку

Екстрактивна сумаризація повторює речення джерела дослівно — без
перефразування. У планах: опційна лематизація для української (pymorphy3)
для об'єднання словоформ перед зважуванням, а також позиційний пріоритет
для текстів у стилі новин.
